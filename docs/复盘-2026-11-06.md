## 四、本次已实施的改进

1. **终态收尾前点名缺报告漏洞**（engine）：goalless done 与 settle 两条收尾路径
   都会检查 evidence 有但 report 空的漏洞并在活动流提示，杜绝"静默空报告交付"。
2. **任务复活自愈**（admission）：从终态复活时自动重开 blocked="context canceled"
   的遗留意图（任务 6/8/9 的 11 条此类意图在新机制下会自动恢复执行），
   用户手动 block 的不受影响；附回归测试。
3. **通道治理（Kali 配置）**：egg-alpha（42% 错误）与 GLM/nemotron/qiniu（60–70%）
   移出轮换池；compactor 钉到主力 DeepSeek-V4.1 通道（0.3% 错误）。
   预期：错误重试成本下降、压缩稳定性提升。
4. **任务 18 已暂停**（按指示停任务）；数据面全量盘点完成。
